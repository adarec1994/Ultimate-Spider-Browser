# Ultimate Spider Browser

Browse, view, explore, and extract the contents of Ultimate Spider-man.

Usage:

1. Install a legitimate copy of Ultimate Spiderman for the PC, or rip a copy from the disk of any of the gamse.
2. Browse to the root directory of the game using the Ultimate Spider-Browser
3. Explore

Currently includes exploring and viewing the contents of all pcpacks, loading and viewing most meshes, exporting meshes.
